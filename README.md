# Rittik Gupta Portfolio

GitHub Pages-ready personal portfolio.

## Files
- `index.html` — site
- `style.css` — design
- `script.js` — interactive experience/project tabs and modal details
- `assets/rittik-gupta.jpg` — profile photo
- `assets/Rittik-Gupta-Resume.pdf` — current resume

## Publish on GitHub Pages
Upload all files/folders to the repository root, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.
