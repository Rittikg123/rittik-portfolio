# Rittik Gupta Portfolio

Responsive single-page portfolio built for GitHub Pages.

## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `rittik-portfolio`.
2. Upload **all files and folders from this folder** to the repository root. Do not upload only `index.html`.
3. Your repository root should contain:
   - `index.html`
   - `style.css`
   - `script.js`
   - `assets/rittik-gupta.jpg`
4. In GitHub: **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.

## Important
The image path is relative (`assets/rittik-gupta.jpg`), which works correctly on GitHub Pages as long as the `assets` folder is uploaded with the site.
