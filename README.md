# Rittik Gupta Portfolio

A responsive, GitHub Pages-ready personal portfolio built with plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Create a new public GitHub repository named `rittik-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open the repository's **Settings**.
4. Select **Pages** in the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. GitHub will display the live website URL after deployment.

## Edit content

Open `index.html` and change the text inside the relevant section. The visual design is controlled by `style.css`.
